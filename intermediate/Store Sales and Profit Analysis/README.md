# 🛒 Store Sales and Profit Analysis using Python

A comprehensive Exploratory Data Analysis (EDA) project on retail store sales and profit data using Python. This project uncovers business insights by analyzing sales trends, profit distribution, customer segments, product categories, regional performance, and shipping methods to support data-driven decision-making.

---

## 📌 Problem Statement

Analyzing the sales and profit performance of a retail store is essential for improving business operations, optimizing pricing strategies, enhancing marketing campaigns, and managing inventory efficiently.

This project leverages Python and data visualization techniques to explore retail sales data, identify key trends, and generate actionable business insights.

---

## 🎯 Objectives

- Perform data cleaning and preprocessing
- Analyze overall sales and profit performance
- Identify top-performing products and categories
- Compare regional and segment-wise sales
- Understand shipping mode preferences
- Discover monthly and yearly sales trends
- Generate visual insights for business decisions

---

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/Abishakm1507/shadowfox.git
```

2. Navigate to the project folder

```bash
cd shadowfox/intermediate
```

3. Install required libraries

```bash
pip install pandas numpy matplotlib seaborn
```

4. Launch Jupyter Notebook

```bash
jupyter notebook
```

5. Open **SuperStore.ipynb** and run all cells.
